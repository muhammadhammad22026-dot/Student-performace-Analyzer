# Student Performance Data Analyzer

A Python-based data analysis project that evaluates student academic performance using marks and attendance. It generates performance reports, calculates subject averages, ranks students, identifies at-risk students, and visualizes results.

## Features

- Calculate individual student averages
- Assign grades based on average marks
- Check pass/fail status
- Calculate class average
- Identify the top-performing student
- Analyze subject-wise averages
- Rank students by performance
- Calculate attendance percentage
- Identify students at academic risk
- Visualize subject averages using Matplotlib

## Technologies Used

- **Python** — Core programming
- **Pandas** — Data analysis and reporting
- **Matplotlib** — Data visualization

## Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/student-performance-data-analyzer.git
   ```

2. Navigate to the project folder:

   ```bash
   cd student-performance-data-analyzer
   ```

3. Install the required libraries:

   ```bash
   pip install -r requirements.txt
   ```

## Usage

Run the Python script:

```bash
python Student_performance.py
```

The program displays student performance reports, class statistics, rankings, and at-risk students. It also generates a subject-average chart.
